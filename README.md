# GPA Brand Projects — Vercel Ready

This is a static HTML website prepared for Vercel.

## Deploy with Vercel

1. Go to https://vercel.com/
2. Sign in or create an account.
3. Choose **Add New → Project**.
4. Upload this project ZIP, or connect a GitHub repository.
5. Framework Preset: **Other** (or leave Vercel to detect it).
6. Build Command: leave empty.
7. Output Directory: leave empty.
8. Click **Deploy**.

## Pages

- `/` — Home
- `/services` — Services
- `/projects` — Projects
- `/about` — About

## Important

This is a static website. Any contact form that requires email delivery/backend processing will need a form service or serverless function before it can send submissions.
